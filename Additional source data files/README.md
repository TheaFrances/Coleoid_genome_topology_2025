# Additional Source Data

This directory contains additional source data files associated with the manuscript.

The file **S2_Octbi_1to20Mb_SourceData.tsv.gz** contains the source data for part of Fig. S2. It comprises the logged interaction frequencies and genomic distance categories for orthologous interacting gene pairs for *E. scolopes* and *O. bimaculoides*. Due to its size, the uncompressed TSV file could not be included in the manuscript's Source Data file and is therefore provided separately in this GitHub repository, as recommended by the journal.

The file has been gzip-compressed for storage on GitHub. It can be decompressed using:

    gunzip S2_Octbi_1to20Mb_SourceData.tsv.gz

This will produce:

    S2_Octbi_1to20Mb_SourceData.tsv
